Informed AI Search · Greedy Best-First vs A*

Focused on Heuristic Search for this lab

Greedy Best-First Search (Informed AI)

Uses only heuristic h(n) to estimate distance to goal. Goal-directed but ignores accumulated cost g(n).

1. Use priority queue ordered by h(n)
2. Expand node with smallest h(n) first
3. Follow heuristic toward goal
4. Not guaranteed optimal

A* Search (Informed AI)

Combines path cost and heuristic: f(n)=g(n)+h(n). With admissible heuristic, finds least-cost optimal path.

1. Use priority queue ordered by f(n)=g(n)+h(n)
2. Track best g(n) for each node
3. Prune worse paths
4. Optimal if h(n) is admissible

Key Difference

Greedy Best-First looks ahead only (heuristic). A* looks behind + ahead (actual cost + heuristic), making it more balanced and optimal in many cases.
