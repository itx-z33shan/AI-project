AI search theory

Uninformed, informed and local search on a directed graph

Breadth-First Search

Expands in layers using a FIFO queue. The first time the target is reached it is reached with the fewest links — but edge costs are ignored, so the route may not be the least effort.

1. Queue = [start]
2. Pop the front node
3. Enqueue undiscovered neighbours
4. First goal found = fewest links

Depth-First Search

Uses a LIFO stack and dives deep along one branch before backtracking. It needs little memory but the path found is not guaranteed to be shortest or least effort.

1. Stack = [start]
2. Pop the top node
3. Push undiscovered neighbours
4. Backtrack when a branch ends

Uniform-Cost Search

Expands the frontier by accumulated cost g(n) using a priority queue. For positive edge costs it returns the minimum total review effort.

1. Heap keyed by g(n)
2. Pop lowest accumulated cost
3. Relax neighbours
4. Optimal cost for positive costs

Greedy Best-First

Uses only the heuristic h(n) to estimate distance to the goal. It is goal-directed but ignores effort already spent, so it can choose a more expensive route.

1. Heap keyed by h(n)
2. Expand the closest estimate
3. Ignore path cost g(n)
4. Not guaranteed optimal

A* Search

Orders the frontier by f(n) = g(n) + h(n). With an admissible heuristic it balances effort spent and estimated effort remaining, and returns the least-effort path.

1. Heap keyed by f(n)=g(n)+h(n)
2. Track best g(n) per node
3. Prune worse paths
4. Optimal if h(n) is admissible

Hill Climbing

A local search that only moves to a strictly closer neighbour. It uses little memory but can climb a decoy and stop at a local optimum or dead end.

1. Move to closest neighbour
2. Accept only if closer
3. Stop when none is closer
4. May miss the global optimum
